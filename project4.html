Over het project

Hoger Lager was mijn eerste programmeerproject tijdens mijn opleiding Software Developer aan ROC Mondriaan.

Het doel was om een interactieve game te maken waarin de speler moet raden of de volgende waarde hoger of lager is.

Toen ik aan dit project begon, had ik nog weinig programmeerervaring. Daarom was het een goede uitdaging om zelf een werkende game te bouwen.

Voor dit project heb ik HTML, CSS en JavaScript gebruikt. Ik heb geleerd hoe ik een webpagina kan opbouwen, vormgeven en interactief kan maken met JavaScript.

Hoewel dit een relatief eenvoudig project is, laat het goed zien waar ik ben begonnen en hoeveel ik sindsdien ben gegroeid als softwareontwikkelaar.
