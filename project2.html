Over het project

Eenden Game Prototype is een game die ik tijdens mijn opleiding Software Developer heb ontwikkeld met GameMaker.

Het doel van dit project was om een werkend gameprototype te maken met verschillende spelmechanieken.

Ik heb onder andere gewerkt aan lopen, springen en multiplayer. Hiermee heb ik ervaring opgedaan met het programmeren van beweging, interacties en gameplay.

Voor het programmeren van de game heb ik GameMaker Language (GML) gebruikt. Dit project heeft mij geholpen om mijn kennis van game development verder te ontwikkelen.
