Over het project

MLD is een muziekwebsite die ik tijdens mijn opleiding Software Developer samen met een klasgenoot heb gemaakt.

Het project was een teamopdracht waarbij we een website ontwikkelden waarop we onze eigen muziek konden aanbieden en verkopen.

Tijdens het ontwikkelen hebben we gewerkt aan het ontwerpen van de website, het bouwen van verschillende onderdelen en het creëren van een functionele gebruikerservaring.

We hebben hiervoor HTML, CSS, JavaScript en PHP gebruikt. Door deze technologieën te combineren konden we zowel aan de vormgeving als aan de functionaliteit van de website werken.

Dit project heeft mij geholpen om beter te leren samenwerken, taken te verdelen en samen met een andere ontwikkelaar aan één website te werken.
